Set up Stripe payments

Connect Stripe once, then use your Stripe products and prices to create paid authentication packs.

  1. 01

    Create your Stripe account

    Start by creating or signing in to your Stripe account.

    Open Stripe ↗
  2. 02

    Add your secret key

    Retrieve the secret key associated with your account. It starts with sk_. Add it to your backend environment as:

    STRIPE_SECRET_KEY
  3. 03

    Create a product and price

    Create a product in Stripe for each pack you plan to offer. For example, a product named Silver can correspond to a Silver pack here. Stripe will generate a price for the product; enter that price ID in the pack form's Stripe Price ID field.

  4. 04

    Configure the webhook

    Production only

    The webhook ensures a role is assigned only after Stripe confirms a successful payment. In Stripe's Workbench:

    1. Open the Webhooks tab.
    2. Click Create an event destination.
    3. Select Your account to listen for events from your own account.
    4. Choose the API version for the events you want to consume.
    5. Select checkout.session.completed as the event to send.
    6. Continue and choose Webhook endpoint as the destination type.
    7. Continue again and enter this endpoint URL, replacing the placeholder with your backend domain:
      https://<your-backend-domain-name>/api/stripe-payment/webhook
    8. On the webhook configuration page, click Reveal secret. Copy the value that starts with whsec_ and add it to your backend environment as:
      STRIPE_WEBHOOK_SECRET_KEY
    Event API reference ↗ Event types ↗
  5. ✓

    You're ready to create packs

    Stripe is configured. You can now create authentication packs and connect each paid pack to its Stripe price.

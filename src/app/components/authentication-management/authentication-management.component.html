Authentication management

Define the authentication packs shown during sign-up, including each pack's name, description, pricing, billing interval, and the role assigned to users who select it. After selecting a pack and clicking on sign up, user will be redirected to Stripe for payment processing.

If no pack is created, it will be a classic sign-up process (only email and password required) and Guest role will be assigned to user.

Prerequisite: Stripe must be configured before creating authentication packs, and a Stripe Price ID is required for each pack. More information on configuring Stripe can be found here: Stripe Documentation.
